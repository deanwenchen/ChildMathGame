# 儿童算术学习工具

一个专为儿童设计的算术学习应用，支持四则运算练习、难度分级和计分系统。

## ✨ 功能特性

- ✅ **四则运算练习**：加法、减法、乘法、除法
- ✅ **难度分级**：简单、中等、困难三个级别
- ✅ **智能题目生成**：减法非负、除法整除
- ✅ **实时计分系统**：基础分 + 难度加成 + 时间奖励
- ✅ **历史成绩追踪**：完整的学习记录
- ✅ **成就系统**：根据得分获得不同称号
- ✅ **儿童友好的界面**：大字体、丰富图标、简单操作

## 🚀 快速开始

### Windows 用户（推荐）

直接双击运行：
```
start.bat
```

脚本会自动：
- 检查 Node.js 环境
- 安装所有依赖
- 启动前后端开发服务器

### Mac/Linux 用户

运行启动脚本：
```bash
chmod +x start.sh
./start.sh
```

### 手动启动

#### 1. 安装依赖

```bash
# 方式1：一键安装所有依赖（推荐）
npm run install:all

# 方式2：分别安装
npm install              # 根目录
cd frontend && npm install
cd ../backend && npm install
```

#### 2. 启动开发环境

```bash
# 同时启动前后端（推荐）
npm run dev

# 前端: http://localhost:5173
# 后端: http://localhost:3000
```

#### 3. 访问应用

打开浏览器访问：**http://localhost:5173**

## 📖 使用指南

### 第一次使用

1. **输入用户名**：在首页输入你的名字（如：小明）
2. **选择练习模式**：
   - 难度：简单 / 中等 / 困难
   - 运算：加法 / 减法 / 乘法 / 除法
3. **开始答题**：每轮10道题目
4. **查看结果**：游戏结束后查看得分和成就
5. **保存成绩**：可以保存成绩查看历史记录

### 难度说明

| 难度 | 适合年龄 | 运算范围 | 特点 |
|------|----------|----------|------|
| 简单 | 6-8岁 | 1-20 | 基础运算，易于上手 |
| 中等 | 8-10岁 | 10-50 | 进阶练习，提升能力 |
| 困难 | 10岁以上 | 50-200 | 挑战高手，锻炼思维 |

### 计分规则

总分 = 基础分 + 难度加成 + 时间奖励（最高100分）

- **基础分**：正确率 × 100
- **难度加成**：中等+5分，困难+10分
- **时间奖励**：最多+20分（答题越快奖励越多）

### 成就等级

- 🌟 **算术大师**：90分及以上
- ⭐ **算术高手**：80-89分
- 👍 **算术能手**：70-79分
- 😊 **进步中**：60-69分
- 💪 **继续努力**：60分以下

## 🔌 API 接口

### 用户相关
- `POST /api/users` - 创建用户
- `GET /api/users/:id` - 获取用户信息

### 成绩相关
- `POST /api/scores` - 提交成绩
- `GET /api/scores/user/:userId` - 获取历史成绩
- `GET /api/scores/user/:userId/summary` - 获取成绩统计

### 题目相关
- `GET /api/questions?difficulty=easy&operation=addition` - 生成题目
- `POST /api/questions/validate` - 验证答案
- `POST /api/questions/calculate-score` - 计算分数
