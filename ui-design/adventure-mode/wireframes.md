### 组件详情

#### 关卡节点 (Level Node)
```css
.level-node {
  width: 80px;
  height: 80px;
  border-radius: 50%;

  /* 已完成 */
  --completed: {
    background: linear-gradient(135deg, #55EFC4, #1DD1A1);
    border: 4px solid #10AC84;
    box-shadow: 0 4px 0 #10AC84;
  }

  /* 当前关卡 */
  --current: {
    background: linear-gradient(135deg, #FFB976, #FF9F43);
    border: 4px solid #E67E22;
    box-shadow: 0 4px 0 #E67E22, 0 0 20px rgba(255,159,67,0.5);
    animation: pulse 1.5s infinite;
  }

  /* 锁定关卡 */
  --locked: {
    background: #DFE6E9;
    border: 4px solid #B2BEC3;
    opacity: 0.7;
  }
}
```

#### 星星评级 (Star Rating)
```
空星：☆  (描边 #B2BEC3)
半星：◐  (左半填充 #FFD700)
满星：★  (填充 #FFD700, 发光效果)
```

### 交互说明
- 点击已解锁关卡：弹出确认对话框 -> 进入关卡
- 点击当前关卡：直接开始挑战
- 点击锁定关卡：显示"需要完成前一关"提示
- 长按章节标题：显示章节详情和奖励

## 屏幕尺寸适配

### 最小支持尺寸
- 手机竖屏：375x667px
- 手机横屏：667x375px
- 平板竖屏：768x1024px
- 平板横屏：1024x768px

### 布局适配策略
```css
/* 基于容器查询的响应式 */
@container (min-width: 768px) {
  .option-grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

@container (min-width: 1024px) {
  .option-grid {
    grid-template-columns: repeat(4, 1fr);
  }
}
```

### 安全区域
```css
/* 避开刘海屏和手势条 */
.safe-area-top: env(safe-area-inset-top);
.safe-area-bottom: env(safe-area-inset-bottom);
```
