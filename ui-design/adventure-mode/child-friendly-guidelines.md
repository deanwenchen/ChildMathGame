# 儿童友好设计指南 (Child-Friendly Design Guidelines)

## 1. 目标用户分析 (Target User Analysis)

### 用户画像 (User Personas)

#### 主要用户：6-8 岁儿童 (Grade 1-2)
```
┌─────────────────────────────────────────────────────────────────┐
│  👧 小美 (7 岁)                                                  │
│                                                                 │
│  特征：                                                         │
│  • 识字量有限，需要图标辅助理解                                  │
│  • 精细动作控制能力发展中                                       │
│  • 注意力集中时间 10-15 分钟                                     │
│  • 喜欢鲜艳色彩和可爱角色                                        │
│  • 对即时反馈和奖励敏感                                          │
│  • 容易挫败，需要正向鼓励                                        │
│                                                                 │
│  设备使用：                                                     │
│  • 主要使用平板 (iPad)                                          │
│  • 偶尔使用父母手机                                              │
│  • 横屏握持为主                                                  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 发展阶段特点

| 年龄 | 认知特点 | 设计启示 |
|------|---------|---------|
| 6 岁 | 具体运算阶段开始 | 需要可视化辅助理解抽象概念 |
| 7 岁 | 注意力 10-15 分钟 | 短关卡设计，及时休息提醒 |
| 8 岁 | 逻辑思维发展 | 逐步增加难度，提供挑战 |

## 2. 触摸交互设计 (Touch Interaction Design)

### 最小点击区域 (Minimum Tap Targets)

```css
/* 推荐尺寸 - 符合儿童手指大小 */
.btn-minimum {
  width: 56px;   /* 最小 56x56px */
  height: 56px;
}

/* 理想尺寸 - 更容易点击 */
.btn-ideal {
  width: 64px;
  height: 64px;
}

/* 主要操作按钮 - 更大更明显 */
.btn-primary {
  min-width: 160px;
  min-height: 64px;
  padding: 16px 32px;
}
```

### 视觉反馈区域
```
┌─────────────────────────────────────────┐
│                                         │
│    实际按钮：[  开始  ]                 │
│              ↓                          │
│    点击区域：[  开始  ] (向外扩展 12px)  │
│                                         │
└─────────────────────────────────────────┘
```

```css
.button {
  /* 视觉尺寸 */
  width: 120px;
  height: 56px;

  /* 通过 padding 扩大点击区域 */
  padding: 12px; /* 每边扩展 12px */
  margin: -12px; /* 补偿布局空间 */
}
```

### 手势要求

| 手势 | 是否使用 | 说明 |
|------|---------|------|
| 单击 | ✅ 主要交互 | 简单明确 |
| 长按 | ⚠️ 谨慎使用 | 需明确提示 |
| 双击 | ❌ 避免使用 | 儿童难以掌握 |
| 滑动 | ⚠️ 有限使用 | 需大范围滑动 |
| 捏合 | ❌ 避免使用 | 精细动作要求高 |
| 拖拽 | ✅ 可使用 | 宽松判定区域 |

### 拖拽交互设计
```css
.draggable-item {
  /* 拖拽时放大，便于抓握 */
  transform: scale(1.1);

  /* 拖拽区域比视觉大 50% */
  hitSlop: { top: 20, bottom: 20, left: 20, right: 20 };
}

.drop-zone {
  /* 掉落区域有明显的视觉边界 */
  border: 3px dashed #54A0FF;
  background: rgba(84, 160, 255, 0.1);

  /* 靠近时自动吸附 */
  snapDistance: 30px;
}
```

## 3. 视觉设计原则 (Visual Design Principles)

### 色彩使用原则

#### ✅ 推荐做法
```
• 使用柔和的饱和度 (60-80%)
• 高对比度确保清晰可见
• 用颜色编码功能类别
• 配合图标一起使用
```

#### ❌ 避免做法
```
• 避免纯黑色背景
• 避免大面积红色 (警示感)
• 避免颜色单独传达信息
• 避免过于刺眼的荧光色
```

### 色彩对比度要求

```css
/* WCAG 2.1 AA 标准 */
.text-normal {
  /* 正文对比度 ≥ 4.5:1 */
  color: #2D3436;  /* on #FFFFFF = 16.1:1 ✓ */
}

.text-large {
  /* 大文字 (≥18pt 粗体) 对比度 ≥ 3:1 */
  color: #636E72;  /* on #FFFFFF = 5.7:1 ✓ */
}

.ui-components {
  /* 界面元素对比度 ≥ 3:1 */
  border-color: #B2BEC3;  /* on #FFFFFF = 2.9:1 ⚠️ */
  /* 建议加粗边框 */
  border-width: 3px;
}
```

### 字号要求

```css
/* 最小字号限制 */
.text-body {
  font-size: 18px;  /* 正文最小 18px (≈13.5pt) */
  line-height: 1.5;
}

.text-button {
  font-size: 20px;  /* 按钮文字最小 20px */
  font-weight: 700;
}

.text-heading {
  font-size: 28px;  /* 标题最小 28px */
  font-weight: 700;
}

.text-display {
  font-size: 48px;  /* 大数字显示 */
  font-weight: 700;
}
```

### 图标设计

```
图标大小层级:

小图标 (24x24px)
┌────────┐
│  ⚙️    │  设置、返回等辅助功能
└────────┘

中图标 (32x32px)
┌──────────┐
│   🎁    │  功能入口、分类标识
└──────────┘

大图标 (48x48px+)
┌────────────┐
│     🐱    │  主要内容、宠物展示
└────────────┘
```

### 图标设计原则

| 原则 | 说明 | 示例 |
|------|------|------|
| 语义清晰 | 图标含义直观 | 🏠 = 首页 |
| 配合文字 | 图标旁加文字说明 | 🎁 每日任务 |
| 风格统一 | 全部使用圆角填充 | 2px 圆角 |
| 色彩一致 | 同功能同颜色 | 设置都用灰色 |

## 4. 认知负荷设计 (Cognitive Load Design)

### 信息层次

```
┌─────────────────────────────────────────────────────────────────┐
│  第一层：核心操作 (最醒目)                                       │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │                    [开始挑战]                            │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                 │
│  第二层：重要信息 (清晰可读)                                     │
│  ⭐⭐⭐  得分：450  第 3 关                                        │
│                                                                 │
│  第三层：辅助信息 (较小)                                         │
│  提示：仔细观察再作答                 🔊 读题                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 单屏信息限制

| 元素类型 | 最大数量 | 说明 |
|---------|---------|------|
| 主要操作按钮 | 2 个 | 避免选择困难 |
| 选项数量 | 4 个 | 标准选择题格式 |
| 同时显示的任务 | 5-7 个 | 短期记忆限制 |
| 动画同时播放 | 1 个 | 避免注意力分散 |

### 注意力引导

```css
/* 使用视觉焦点引导 */
.attention-focus {
  /* 高亮当前操作区域 */
  box-shadow: 0 0 0 4px rgba(255, 159, 67, 0.5);

  /* 其他区域轻微变暗 */
  filter: brightness(0.9);
}

/* 使用动效引导 */
@keyframes gentle-pulse {
  0%, 100% { transform: scale(1); }
  50% { transform: scale(1.05); }
}

.attention-pulse {
  animation: gentle-pulse 2s infinite;
}
```

## 5. 反馈与激励设计 (Feedback & Motivation Design)

### 即时反馈类型

| 反馈类型 | 时长 | 用途 |
|---------|------|------|
| 触觉反馈 | 50ms | 按钮点击 |
| 音效反馈 | 200-500ms | 操作确认 |
| 视觉反馈 | 300-800ms | 结果展示 |
| 动画反馈 | 1000-2000ms | 成就庆祝 |

### 正向反馈设计

```
✅ 正确回答时的反馈序列:

1. 按钮变绿色 (0ms)
   ┌──────────────┐
   │ ✓ 42  ✓     │  绿色背景 #55EFC4
   └──────────────┘

2. 播放成功音效 (100ms)
   🎵 "叮~" (高音调，愉悦)

3. 分数动画 (300ms)
   ✨ +100 分 ✨ (从按钮飞出)

4. 星星飞溅 (500ms)
   ⭐ ⭐ ⭐ (从屏幕下方飞入)

5. 进度条增长 (800ms)
   ████████░░░░░░░░ → ████████████░░░░
```

### 错误处理设计

```
❌ 错误回答时的反馈序列:

1. 按钮变红色 (0ms)
   ┌──────────────┐
   │ ✗ 32  ✗     │  柔和红色 #FF9999
   └──────────────┘

2. 播放提示音效 (100ms)
   🔔 "唔~" (低音调，非惩罚性)

3. 轻微震动 (200ms)
   📳 短暂震动 (50ms)

4. 显示正确答案 (500ms)
   正确答案是：42

5. 鼓励语 (800ms)
   💪 "加油，下次一定行！"
```

### 挫败感预防

```css
/* 连续错误 3 次后的帮助机制 */
.streak-wrong-3 {
  /* 降低难度 */
  difficulty: 'easy';

  /* 提供提示 */
  showHint: true;

  /* 播放鼓励动画 */
  playEncouragement: true;
}
```

```
┌─────────────────────────────────────┐
│                                     │
│   💡 小提示                         │
│                                     │
│   试试把 25 拆成 20 + 5              │
│   17 拆成 10 + 7                     │
│                                     │
│   20 + 10 = 30                      │
│   5 + 7 = 12                        │
│   30 + 12 = 42                      │
│                                     │
│         [明白了]                     │
│                                     │
```

## 6. 文字与语言设计 (Text & Language Design)

### 用词难度控制

| 年级 | 识字量 | 设计建议 |
|------|-------|---------|
| 一年级 | 800-1200 字 | 使用最常见字，配合拼音 |
| 二年级 | 1600-2000 字 | 可使用常用词，避免生僻字 |

### 文字规范

```
✅ 推荐用语:
• "真棒！" (具体表扬)
• "继续加油！" (鼓励)
• "再试一次吧~" (温和建议)
• "你已经很接近了！" (过程肯定)

❌ 避免用语:
• "错了" (直接否定)
• "太简单了" (贬低)
• "这都不会" (打击)
• "失败" (负面标签)
```

### 句子长度

```css
/* 按钮文字 */
.btn-text {
  max-characters: 6;  /* 最多 6 个字 */
  /* 例：[开始挑战] [领取奖励] */
}

/* 提示文字 */
.hint-text {
  max-sentence: 12;  /* 每句最多 12 字 */
  max-lines: 2;      /* 最多 2 行 */
}

/* 题目描述 */
.question-text {
  max-characters: 40;  /* 题目最多 40 字 */
}
```

### 拼音支持 (可选)

```jsx
// 为复杂汉字添加拼音标注
<PinyinText text="奖励">
  <Pinyin position="top">jiǎng lì</Pinyin>
</PinyinText>

// 显示效果:
//   jiǎng lì
//   奖 励
```

## 7. 可访问性设计 (Accessibility Design)

### 色盲友好设计

```
不单独依赖颜色传达信息:

❌ 错误示例:
   红色按钮 = 错误，绿色按钮 = 正确
   (红绿色盲无法区分)

✅ 正确示例:
   红色按钮 + ✗ 图标 = 错误
   绿色按钮 + ✓ 图标 = 正确
```

### 声音设置

```
┌─────────────────────────────────────┐
│           声音设置                   │
│                                     │
│   🔊 音效          [●━━━━] 80%     │
│                                     │
│   🎵 背景音乐      [●━━━━] 60%     │
│                                     │
│   🔊 语音读题      [━━●━━] 50%     │
│                                     │
│   ┌─────────────────────────────┐  │
│   │ 🔇 静音模式                  │  │
│   └─────────────────────────────┘  │
│                                     │
└─────────────────────────────────────┘
```

### 动画减弱支持

```css
/* 检测用户系统设置 */
```

## 8. 安全与健康设计 (Safety & Health Design)

### 用眼健康

```
• 避免纯黑/纯白强烈对比
• 使用柔和的背景色 (#FFF8F0 奶油白)
• 文字对比度适中 (非极端黑底白字)
• 每 15 分钟提醒休息

┌─────────────────────────────────────┐
│                                     │
│      👀 眼睛休息时间到！            │
│                                     │
│   看向远处，休息一下吧~              │
│                                     │
│   休息 30 秒  │  稍后提醒 (5 分钟)     │
│                                     │
└─────────────────────────────────────┘
```

### 使用时长控制

```javascript
// 建议单次使用时长
const USAGE_LIMITS = {
  continuous: 20 * 60 * 1000,  // 连续使用 20 分钟提醒
  daily: 60 * 60 * 1000,       // 每日使用 60 分钟提醒
  break: 5 * 60 * 1000,        // 建议休息 5 分钟
};
```

### 隐私保护

```
• 不收集儿童个人信息
• 不显示真实姓名 (使用昵称/动物名)
• 不开放陌生人社交功能
• 家长控制开关
```

## 9. 设计检查清单 (Design Checklist)

### 视觉检查
- [ ] 所有文字 ≥ 18px
- [ ] 按钮最小 56x56px
- [ ] 色彩对比度 ≥ 4.5:1 (正文)
- [ ] 图标配合文字说明
- [ ] 重要操作有视觉焦点

### 交互检查
- [ ] 单击是唯一必需手势
- [ ] 拖拽有宽松判定区域
- [ ] 所有操作有即时反馈
- [ ] 错误有明确恢复路径
- [ ] 加载有进度指示

### 认知检查
- [ ] 单屏信息 ≤ 7 个元素
- [ ] 文字 ≤ 二年级识字水平
- [ ] 图标含义直观
- [ ] 无歧义的操作说明
- [ ] 一致的设计语言

### 情感检查
- [ ] 正向鼓励用语
- [ ] 无惩罚性设计
- [ ] 挫败时有帮助机制
- [ ] 成就有庆祝反馈
- [ ] 可爱的角色形象

### 健康检查
- [ ] 用眼健康提示
- [ ] 休息提醒机制
- [ ] 时长控制功能
- [ ] 动画可减弱
- [ ] 声音可调节
