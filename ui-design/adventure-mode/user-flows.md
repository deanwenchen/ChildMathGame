### 状态说明
| 状态 | 视觉反馈 | 可操作 |
|------|---------|--------|
| 未解锁 | 灰色、锁图标 | 点击显示提示 |
| 可挑战 | 橙色、脉动动画 | 点击直接开始 |
| 已完成 | 绿色、星星显示 | 点击可重玩 |

### 转场动画规范

| 导航类型 | 动画效果 | 时长 |
|---------|---------|------|
| 进入下一级 | 从右滑入 | 300ms |
| 返回上一级 | 从右滑出 | 300ms |
| 打开弹窗 | 从中心放大 + 淡入 | 250ms |
| 关闭弹窗 | 缩小 + 淡出 | 200ms |
| 标签切换 | 淡入淡出 | 200ms |
| 模态全屏 | 从下向上滑入 | 350ms |
